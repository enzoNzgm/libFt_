# libft

Premier projet de l'école 42 Paris : une bibliothèque C réunissant des fonctions de base, réécrites à la main pour servir dans tous les projets suivants.

## Contenu

- **Fonctions libc** : `ft_strlen`, `ft_memcpy`, `ft_strdup`, `ft_atoi`, `ft_calloc`, `ft_split`…
- **Fonctions utilitaires** : `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_itoa`, `ft_putstr_fd`…
- **Bonus — listes chaînées** : `ft_lstnew`, `ft_lstadd_back`, `ft_lstmap`, `ft_lstclear`…

## Compilation

```bash
make        # produit libft.a
make bonus  # inclut les fonctions de listes chaînées
```
